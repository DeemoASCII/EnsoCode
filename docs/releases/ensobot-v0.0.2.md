# EnsoBot 0.0.2 Preview

EnsoBot 独立预发布版，与 EnsoCode 共用仓库，但安装身份、用户数据与更新通道互相隔离。本发布不替换 EnsoCode 的 Latest。

## 本次更新

- **主持人群聊**：未点名的消息由主持人接手；成员可互相 @、分工与回报，主持人汇总。支持建群后修改主持人和每群接力上限。
- **工作可见**：成员进度、人工等待状态和可展开的工作记录；支持查看工具参数、实际文本输出、失败原因与耗时。修复流式参数摘要停在空值或半截的问题。
- **聊天体验**：Markdown 表格、粗体、代码与 @ 高亮；群设置和记录跨重启保留。
- **恢复行为**：尚未送出的排队消息继续投递；已运行的轮次遇到应用重启或 worker 退出时，在原聊天面明确说明中断，不擅自重做工具操作或重放授权。
- **同级窗口**：关闭工作台不会关闭 Bot 窗口；退出整个应用仍使用托盘退出。
- **持续验收**：发布流水线增加模拟真人的 Electron 前端测试，覆盖协作、工作证据、审批、群设置与重启。

## 安装与升级

- Windows：`EnsoBot-Setup-0.0.2.exe`。
- macOS：选择对应 Apple Silicon（arm64）或 Intel 的 DMG / ZIP。
- Linux：AppImage / DEB。
- EnsoBot 0.0.1 可通过专属更新通道升级；数据目录继续使用 `ensobot`，不会自动导入或覆盖 `enso-code` 的会话。
- 校验值见 `SHA256SUMS.txt`。

## 预览边界

- 默认权限仍为全程审批，成员间转述不能代替用户授权。
- 旧版本工作记录未保存的参数/输出无法事后补齐，界面明确标注。
- “团队动态”目前为成员状态概览，不是跨成员的完整活动时间线。
- 本轮没有新增两台物理节点的端到端验收；不要把本地测试视为所有远程网络环境均已覆盖。
- 本版基于已合入的 EnsoCode 0.2.2 底座，不混入主线后续 SDK 1.0 / 工具协议升级。
