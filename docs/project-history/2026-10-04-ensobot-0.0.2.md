# EnsoBot 0.0.2 发布准备与验收

## 范围

用户授权在问题修复并验证后推送、发布 `ensobot-v0.0.2` 非 Latest 预发布。
基于本地 `61aefe08` 及两轮主持人改造；远端 `origin/ensobot` 为 `6016257b`，可快进，不强推。
实际查询确认 `ensobot-v0.0.1` 已发布、正式 Latest 为 `v0.2.3`。
未额外合入 main 的 66 个 SDK 1.0 / 工具协议升级提交；未带入请求体统计等另一会话的并行改动。
使用独立工作树 `D:/WORK/EnsoBot-release-0.0.2` 按清单收集 EnsoBot 改动，原工作树的其他修改保持原样。

## 修复

- Main：所有来源的 active/dispatched 活轮重启或 worker 退出均在真实来源留下中断说明，去重且不重放。
- shared：同工具 ID 的流式参数更新不再被丢弃；保留已投影参数、文本输出及耗时，拒绝与执行失败区分。
- renderer：工作记录可展开查看证据，群列表正确区分人工阻塞、排队和工作。
- 初版完整证据增加了快照尺寸，复审发现会超过 pair 的 1,000,000 字节阈值导致远端停更；已改为
  Main 权威证据 + snapshot 元数据白名单 + 按需分块读取。每块 16,000 字符，UUID 定位而非磁盘路径，
  revision 防跨版本拼接。单连接成功/错误回执经过实际加解密双 socket 测试，不广播证据。
- “团队动态”暂为成员状态概览，不宣称实现了完整跨成员活动时间线。

## 回归与真机证据

- 按测试先行修复：先复现流式参数冻结、来源中断漏报、快照超限等失败，再通过实现使回归变绿。
- 分块后 backend / 协议 / 双连接验证 163 项通过；renderer 分块重读/无效游标 3 项通过。
- 最终独立树 typecheck、全仓 Biome 通过。
- 标准 Linux `pnpm typecheck && pnpm lint && pnpm test` 通过：557 文件通过、1 原有跳过，
  **6112 用例通过、5 原有跳过**。普通用户、Node 22.22.2、Git 2.48.1、pnpm 10.26.2；未放宽断言。
  Electron 下载需要显式继承代理，早先安装停在 postinstall 的超时不算门禁通过。
- Windows 全量仍为 26 文件 / 79 项失败（6027 通过、11 跳过）；平台相关失败不计作通过。
- 重建后的模拟真人 Electron e2e **6/6 通过**（21.10 秒），包含超过 20 KB 的实际工具输出分页读取，
  协作、Markdown、审批、群设置、直接 @ 活轮重启中断且无授权重放。
- 最终两模型默认 `supervised` 真机验证通过（27.58 秒）：inyx Fable / Anthropic Messages 与 Astra /
  OpenAI Responses，逐次人工允许真实 PowerShell 命令，再在界面从 Main 读取真实参数与结果。
  不以模型自述或 IPC 直接回应代替界面操作。临时脚本和含凭据 profile 已删除。
- Windows 构建已成功；空间不足的首次打包已清理，仅调整验证产物目录到系统 temp，不改变产品身份。
  分发以 CI 对发布提交重新构建的四平台矩阵和原生模块 smoke 为准。
